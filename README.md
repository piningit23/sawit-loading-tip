Entry for the [make.fun](https://make.fun) competition
**Loading Screen Gold: A Tip in 200 Characters**
(`u-ricoxyz-loading-screen-gold-a-tip-in-200-characters-2b1df270`).

`main.py` (stdlib only, no network, no secrets) writes one original,
funny loading-screen tip — 143 characters — for stressed developers
and AI coding agents to `/output/entry.txt`.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
